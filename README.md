## Complex Time-Steppers: A Stability Analysis

This project investigates the stability of numerical methods—Euler's Forward and Backward, and Runge-Kutta 4—when extended to **complex time steps**. It includes:

- Analytical derivations
- Python scripts for visualization
- Stability region animations
- A complete academic writeup and poster

Read the full [report](Report/report.pdf) for an in-depth explanation of the project.
